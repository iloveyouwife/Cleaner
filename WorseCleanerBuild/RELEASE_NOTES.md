## Cleaner v0.95.0 — 全界面容器数量严格对齐与状态/清洗细节完善

- **首页上下容器数量彻底对齐**：`WCScanExclusions.eligibleTargets` 同步排除首页列表不显示的 6 个内部系统服务，并处理扫描期才识别出的内部服务，使未搜索时顶部卡片“`N 个数据容器`”与下方三大分组（`已识别名称` + `仅识别 Bundle ID` + `未识别数据容器`）括号数量之和严格相等。
- **底部运行结果文案对账补全**：发现阶段统一显示实际可扫描项数（如有手动排除或内部服务过滤则附带说明）；扫描完成文案补齐“`未识别 C 个`”，确保可访问数等于三类之和。
- **多 App Group 切换与联网补全状态保护**：切回已确认的专用 App Group 时自动清除旧提示并刷新列表；联网补全名称异步写回前再次核验 `canDiscoverApps` 授权状态。
- **名称字符安全清洗与大 inode 卷回退适配**：从 App Store 与安装包 `Info.plist` 读取的名称统一经过 `safeName` 去除首尾空白、过滤控制字符/双向伪装字符并限制长度；安装包名称回退的 `pathleak` 上限自适应当前 Data 卷真实 inode 范围（500 万～5000 万）。
- **工程配置与工作流清理**：在 `project.yml` 补齐支持方向声明以消除 Xcode 编译警告，清理已归档的 `v89`/`v90` 历史专项工作流；7 个受保护 UI 文件哈希、发现策略、授权参数与 `Caches`/`tmp` 白名单保持不变，新增 3 项单元测试（共 70 项单测）。

附件为未签名 IPA，需使用自己的有效签名与独占 App Group。
